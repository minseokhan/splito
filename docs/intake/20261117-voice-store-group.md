# Intake: 말로 입력 — 가게별 묶음 + 드래그 (Splito UXUI (3) / splito-voice-handoff 개정판)

1차 소스: `code/voice-template.html`(인라인 수치), `code/voice-logic.js`(`voiceVals`·`voiceEdit`). README는 요약이다.
사용자 지시(2026-11-17)가 시안을 덮는 곳: 가게 이름은 품목 편집이 아니라 **카드 위 가게명을 눌러** 고친다. AI가 가게를 판단하지 못한 품목은 **맨 아래 따로** 두고 끌어 넣게 한다(시안에 없음).
선행: `20261115-voice-input.md`(카드 1장 = 지출 1건 판본). 이 판본으로 대체된다.
