# UI 디자인 가이드

확정 디자인은 `docs/design/`(핸드오프)이 정답이다. 화면별 수치는 `docs/design/HANDOFF.md`, 원본 프로토타입은 `docs/design/splito-app.dc.html`(같은 폴더의 `support.js`와 함께 `npx serve docs/design`로 연다), 토큰은 `docs/design/splito-tokens.json`. 이 문서는 구현용 요약이다. 기준 폭 390pt, 좌우 패딩 20 고정, 라이트 모드·세로 화면.

## 디자인 원칙
1. **여행처럼 가볍게, 장부처럼 또렷하게.** 스카이(primary)는 대표 행동과 강조, 숫자와 근거는 진한 잉크색.
2. **숫자에는 항상 근거가 붙는다.** 원화 옆에 외화 원본, 결제자·기록자, 환율 근거, '확인필요'를 붙인다.
3. **한 화면, 한 가지 행동.** 주요 버튼은 하단 고정 CTA 하나.
4. **엄지로 쓴다.** 터치 영역 최소 44×44.

## 하지 마라
| 금지 | 이유 |
|------|------|
| 스카이(`primary`) 배경 위에 `primary-text`(같은 계열) | 글자가 묻힌다. primary 배경 위 글자는 `primary-on`(#FFFFFF) |
| 틴트 배경(`sky-*`) 위 흰 글자 | 대비 부족. 틴트 위 글자는 `ink` 또는 `primary-text` |
| 비활성 버튼에 투명도 | 회색 배경(`line`)+`ink-300` 글자로 표시 |
| 반투명 블러 카드, 그라데이션 텍스트, 글로우·네온 | 장부 앱의 신뢰감을 해친다(하단 CTA 위 흰색 페이드만 예외) |
| "AI가 분석 중 ✨" 장식 문구 | 로딩 문구는 "영수증을 읽고 있어요"처럼 사실만 |
| 토큰 밖 임의 색 | 아래 토큰과 멤버 색만 쓴다 |

장식은 브랜드 마크만 허용한다(계좌 카드 마크, 로그인·정산 헤더 마크). 홈 카드 배경 실루엣은 2026-11-04 시안에서 삭제됐다.

브랜드 마크는 `SplitoMark`(S + 출발 삼각형 + 금색 별, `assets/logo/svg/splito-mark.svg`) 하나다. 구 '반짝 지갑' 심볼은 폐기했다.

## 타이포그래피
Pretendard 하나만(Regular·Medium·SemiBold 3종만 expo-font로 번들). **굵기는 SemiBold 600 / Medium 500 / Regular 400 만 쓴다 — 700·800 금지.** 행간 160%, 자간 0, 한국어 `word-break: keep-all`. 시스템 글꼴 크기는 최대 1.3배.

크기 스케일: H1 28 · H2 24 · H3 20 · H4 18 · B1 17 · B2 16 · B3 14 · B4 13 · C1 12. **이 9개 밖의 값(26·32·22·15)은 쓰지 않는다.**

| 상세 히어로 총액 | 28 / 600 |

| 로그인 메인카피 · 시트 제목 | 20 / 600 |

## 반경·크기·간격
- 반경(2026-11-20, 노션 UI 업데이트 14번): 태그·배지·썸네일 8(`rounded-badge`), 토글 안 선택 칸 10(`rounded-toggle`), 버튼·입력 12(`rounded-button`·`rounded-input`·`rounded-chip`), 요약 카드·날짜 묶음 카드·회색 박스 16(`rounded-box`), 바텀시트 위쪽·일반 큰 카드 20(`rounded-card`·`rounded-t-sheet`), 홈 여행 카드 28(`rounded-hero`), 칩·아바타·카테고리 원 pill(`rounded-full`). 중첩: 안쪽 = 바깥 − 안쪽 여백에 가장 가까운 토큰.
- 크기: 버튼 56, 보조 버튼 52, 입력 54, 칩 34, 아이콘 타일 44, 아바타 32/36/38, 상태바 50, 내비 52.
- 간격: 화면 패딩 20, 섹션 22~28, 카드 내부 14.

## 컴포넌트 (`src/components/`)
- **PrimaryButton**: `variant` primary(하늘색/`primary-on`), dark(`ink`/흰색), muted, sky, kakao, naver, danger. 비활성 `line`/`ink-300`. 눌림은 1px 아래로 + 한 단계 진한 배경.
- **BottomBar**: 하단 고정 CTA 영역, 패딩 `12 20` + 안전 영역. `fade`면 위로 흰(또는 `app`) 페이드. 스크롤 콘텐츠는 하단 130~140 여백.
- **NavBar**: 뒤로(nav-arrow-left 28, 패딩 8) 또는 닫기(xmark 26), 제목 17/600 좌측 또는 가운데.
- **Avatar / AvatarStack**: 원형, 이름 첫 글자, 멤버 tint/fg. 게스트는 점선 테두리 + `GuestChip`. 히어로 위 겹침은 `ring`(배경색 2.5 테두리), -8 겹침.
- **Badge**: '확인필요' 12/600 `warning` on `warning-badge`, radius 6, 2×6. 누르면 해제.
- **StatusChip**: 12/600, 흰 배경 radius 8, 패딩 4×8. 정산 중 `primary-text`, 기록 중·정산 완료 `success`.
- **아이콘 타일**: 44, radius 14, `muted` 배경, 아이콘 `primary-text` 21 — 입력 방식(사진=camera, 문자=message-text, 음성=microphone, 직접=edit-pencil).
- **BottomSheet**: 스크림 `rgba(19,25,39,.45)`, 상단 radius 28, 핸들 40×5, 제목 20/600 + 부제 14.
- **Toast**: 하단 120 위, `ink` pill, check-circle `success-icon`(민트), 14/600, 1.8초.
- **입력 필드**: 54h, radius 14, 테두리 1.5 `line`, 포커스 시 테두리 `primary` + `0 0 0 4px rgba(94,196,255,.18)`. 라벨 13/600 `ink-500`. 에러는 테두리 `danger` + 아래 13 `danger` 문구.
- **로고**: `SplitoSymbol`(그라데이션 지갑, `variant` color/white/navy), `Wordmark`(아웃라인 SVG, `variant` ink #0E2A47 / white). 핸드오프 `assets/logo/svg/` 의 도형을 그대로 재현한 것이며 텍스트로 그리지 않는다.

## 애니메이션
바텀시트 진입 320ms `cubic-bezier(0.2,0.8,0.2,1)`(fade + 위로), 상태 색 전환 120ms, 토스트 페이드, 새 피드 항목 페이드인 200ms. 바운스 없음. "동작 줄이기" 설정이면 끈다.

## 접근성
텍스트 대비 4.5:1(큰 텍스트 3:1). 금액은 "132,000원 받을 돈"처럼 읽히게 라벨을 붙인다.
