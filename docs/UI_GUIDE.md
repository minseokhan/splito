# UI 디자인 가이드

## 디자인 원칙
1. **여행처럼 가볍게, 장부처럼 또렷하게.** 하늘색은 분위기를 담당하고, 숫자와 근거는 진한 잉크색으로 또렷하게 보여준다.
2. **숫자에는 항상 근거가 붙는다.** 금액 옆에는 환율 근거, 결제자, '확인 필요' 상태를 빠뜨리지 않는다.
3. **한 화면, 한 가지 행동.** 각 화면의 주요 버튼은 하나다(하단 고정 CTA).
4. **엄지로 쓴다.** 주요 조작은 화면 하단 2/3 안에 두고, 터치 영역은 최소 44×44pt로 한다.

## AI 슬롭 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| 반투명 블러(BlurView) 카드 | glass morphism은 AI 템플릿의 가장 흔한 징후 |
| 그라데이션 텍스트 | AI가 만든 SaaS 랜딩의 대표 특징 |
| "AI가 분석 중 ✨" 장식 문구·배지 | 기능이 아니라 장식이다. 로딩 문구는 "영수증을 읽고 있어요"처럼 사실만 쓴다 |
| 글로우·네온 그림자 애니메이션 | 장부 앱의 신뢰감을 해친다 |
| 보라/인디고 색상 | "AI = 보라색" 클리셰. 브랜드는 하늘색 하나 |
| 모든 요소에 같은 큰 라운드 | 템플릿 느낌. 아래 반경 규칙을 따른다 |
| 배경 장식 원형·blob | 정보가 없는 장식 |
| 하늘색 위 흰 글자 | 대비 2.26:1로 읽기 어렵다(아래 색상 규칙) |

## 색상
### 브랜드 (Secondary 토큰 = 이 앱의 메인 컬러)
| 토큰 | 값 | 용도 |
|------|------|------|
| `sky-100` | `#F5FBFF` | 화면 배경 틴트, 선택되지 않은 칩 배경 |
| `sky-200` | `#E6F6FF` | 카드 강조 배경(내 순잔액 카드), 입력 포커스 배경 |
| `sky-300` | `#D7F0FF` | 선택된 칩·탭 배경. 그 위 글자는 `ink-900`(sky-900은 4.21:1로 미달) |
| `sky-400` | `#B8E5FF` | 구분선 강조, 진행 바 트랙 |
| `sky-600` | `#80D1FF` | 아바타 기본 배경, 일러스트 |
| `sky-800` | `#36B6FF` | **메인 컬러.** Primary 버튼 배경, 활성 탭 아이콘, 진행 바, FAB |
| `sky-900` | `#0874BB` | **[추가 토큰]** 흰 배경 위 링크·강조 텍스트·포커스 링(대비 4.97:1) |

### 배경·표면
| 용도 | 값 |
|------|------|
| 앱 배경 | `#FFFFFF` |
| 섹션 배경 | `sky-100` `#F5FBFF` |
| 카드 | `#FFFFFF` + 테두리 `#E3EAF0` |
| 구분선 | `#EEF2F5` |

### 텍스트 (잉크)
| 용도 | 값 | 흰 배경 대비 |
|------|------|------|
| 주 텍스트·금액 | `ink-900` `#0B2540` | 15.5:1 |
| 본문 | `ink-700` `#33475B` | 9.5:1 |
| 보조 | `ink-500` `#5E7185` | 5.0:1 |
| 비활성 | `ink-300` `#9AA8B6` | 장식용만 |

### 시맨틱
| 용도 | 값 | 사용처 |
|------|------|------|
| 받을 돈(+) | `#077A4C` | 순잔액 양수, "받았어요" |
| 줄 돈(−) | `#D93A3A` | 순잔액 음수, 에러 |
| 확인 필요 | 배경 `#FFF4D6`, 텍스트 `#8A5A00` | 배지·박스 테두리 |
| 환율 대기 | 배경 `#EEF2F5`, 텍스트 `#33475B` | 배지 (`#5E7185`는 이 배경에서 4.47:1로 미달) |
| 정산 완료 | 배경 `#E3F6EC`, 텍스트 `#0A6B44` | 방 상태 칩, 송금 "확인됨" |
| 확인 대기(송금) | 배경 `#E6F6FF`, 텍스트 `#0B2540` | 한쪽만 기록한 송금 |
| 무효(취소·못 받음) | 텍스트 `#5E7185` + 취소선 | 송금 기록 |

> 색만으로 상태를 전달하지 않는다. 금액에는 항상 `+`/`−` 부호와 "받을 돈/줄 돈" 라벨을 붙인다.

## 컴포넌트 (NativeWind 클래스)
### 버튼
```
Primary  : h-14 rounded-xl bg-sky-800 active:bg-[#1FA3F0]  텍스트 text-ink-900 text-base font-bold
Secondary: h-14 rounded-xl bg-sky-200  텍스트 text-ink-900 font-semibold (sky-900 글자는 sky-200 위에서 4.49:1로 미달)
Text     : text-sky-900 font-medium (h-11 이상 터치 영역)
Danger   : h-14 rounded-xl bg-white border border-[#F2C4C4] 텍스트 text-[#D93A3A]
비활성   : opacity-40, 탭해도 반응하지 않음 + 이유 문구를 버튼 위에 표시
```
Primary 버튼 글자는 흰색이 아니라 **`ink-900`**이다(하늘색 위 흰 글자 금지).

### 카드
```
지출 카드: rounded-lg bg-white border border-[#E3EAF0] px-4 py-3
  1행: 가맹점(text-base font-semibold ink-900)        원화 금액(text-base font-bold ink-900, 숫자 tabular)
  2행: 결제자 아바타 · 시각 · 입력 방식 아이콘(ink-500)  외화 원본 "¥3,280"(ink-500)
  배지 줄: 확인 필요 / 환율 대기 / 중복 의심
```

### 품목 박스 (핵심 UI)
```
rounded-md border border-[#E3EAF0] bg-white p-3
  품목명(원문) text-sm ink-500  →  번역명 text-base font-semibold ink-900
  수량 × 금액                       우측: 겹친 원형 아바타(24px, -8px 겹침, 최대 4개 + "+2")
  지정 없음 → "전원" 칩(bg-sky-100 text-sky-900)
  확인 필요 → border-[#F0C14B] + 좌상단 배지
쪼개기·추가: 박스 하단 텍스트 버튼
```

### 입력 필드
```
h-12 rounded-lg bg-white border border-[#D5DEE6] px-4 text-base
포커스: border-sky-800 bg-sky-100
에러: border-[#D93A3A] + 아래 text-sm text-[#D93A3A] 메시지
금액 입력: 숫자 키패드, 천 단위 콤마 실시간 표시, 통화 기호 접두
```

### 아바타
원형이고 이니셜 1글자를 표시한다. 배경은 사람마다 고정 색(합류 순서 기준 `sky-600`, `#FFD27A`, `#A8E6C9`, `#FFB3B3`, `#C9D7FF` 순환), 글자는 `ink-900`.

### 로그인 버튼
각 제공자의 브랜드 가이드를 따른다. 브랜드 색을 하늘색으로 바꾸지 않는다.
- 카카오: 배경 `#FEE500`, 심볼과 글자 `#000000` 85%, "카카오 로그인"
- 네이버: 배경 `#03C75A`, 흰 로고, "네이버 로그인"
- Apple(iOS): `expo-apple-authentication`의 기본 버튼(검정)
- 높이는 모두 52로 같게 맞추고 세로로 쌓는다. 순서는 카카오 → 네이버 → Apple이다.

### 송금 카드
```
rounded-lg border border-[#E3EAF0] p-4
  "민지 → 지훈"(15 SemiBold)                 132,000원(20 Bold tabular)
  계좌 줄: 내가 줄 사람일 때만 원문, 그 외에는 마스킹 / 미등록이면 "계좌 미등록 · [계좌 요청하기]"
  액션: [복사](Secondary) [보냈어요](Primary) — 받을 사람 화면에는 [받았어요](Primary) [못 받았어요](Text)
  상태 칩: 확인 대기 / 확인됨 / 취소됨 / 못 받음
```

### 게스트 아바타
일반 아바타와 같은 원형에 **점선 테두리**(1.5px `#5E7185`)를 두르고, 이름 옆에 "게스트" 칩(12 SemiBold, 배경 `#EEF2F5`, 텍스트 `#33475B`)을 붙인다. 사람별 표에서는 "엄마(게스트 · 대표 민지)"로 표기한다. 송금 카드에는 게스트가 나오지 않고, 대표자 카드에 "엄마 몫 포함"을 보조 텍스트로 표시한다.

### 바텀시트
사람 지정, 합류 확인, 입력 방식 선택은 바텀시트로 한다. 상단 라운드 16, 손잡이 바를 둔다.

## 레이아웃
- 좌우 여백 20, 섹션 간격 24, 카드 사이 8.
- 정렬: 좌측 정렬이 기본이다. 금액은 우측 정렬, `fontVariant: ['tabular-nums']`.
- 하단 고정 CTA: SafeArea 하단 + 16, 키보드가 올라오면 함께 올라간다.
- 장부 홈의 지출 추가는 우하단 FAB(56, `sky-800`, 아이콘 `ink-900`)로 한다.
- 반경: 버튼·큰 카드 12, 지출 카드·입력 8, 품목 박스·칩 6, 바텀시트 상단 16.

## 타이포그래피
폰트: **Pretendard**(expo-font로 번들). 시스템 글꼴 크기 설정을 따르되 최대 1.3배까지만 키운다.
| 용도 | 스타일 |
|------|--------|
| 화면 제목 | 22 / Bold / ink-900 |
| 큰 금액(순잔액·총지출) | 28 / Bold / tabular |
| 섹션 제목 | 17 / SemiBold / ink-900 |
| 본문 | 15 / Regular / ink-700 / 행간 1.5 |
| 보조·근거 | 13 / Regular / ink-500 |
| 배지 | 12 / SemiBold |

금액 표기: `132,000원`(원화), `¥3,280`, `$12.50`. 환율 근거: `10/21 매매기준율 · 100엔 = 912.34원`(엔화·루피아는 100단위로 표시: `100엔 = 912.34원`, `100루피아 = 8.61원`).

| 피드 날짜 그룹 | "10월 21일 (화)" / 방 기간 시작 전 지출은 "여행 전" 그룹 |

## 애니메이션
- 허용: 바텀시트 슬라이드(250ms), 새 피드 항목 페이드인(200ms), 버튼 눌림 스케일 0.98, 송금 완료 체크 표시(300ms 한 번).
- 그 외 금지. 시스템의 "동작 줄이기" 설정을 켜면 모두 끈다.

## 아이콘
- `lucide-react-native`, strokeWidth 1.75, 크기 20/24.
- 아이콘을 둥근 배경 박스로 감싸지 않는다(FAB는 예외).
- 입력 방식 아이콘: 카메라(영수증), 메시지(문자), 마이크(음성), 펜(직접 입력).

## 접근성
- 모든 아이콘 버튼에 `accessibilityLabel`을 단다(예: "영수증 사진으로 지출 추가").
- 텍스트 대비는 최소 4.5:1, 큰 텍스트는 3:1을 지킨다.
- 금액은 스크린리더가 "132,000원 받을 돈"처럼 읽도록 라벨을 붙인다.
