## Claude Code 요청 예시
> `splito-full-handoff/README.md`를 먼저 읽고, `specs/` 문서도 읽어줘.
> `screens/` 캡처와 `prototype/Splito App.dc.html`의 1a 프로토타입을 기준으로, 우리 앱(Expo/React Native)에 화면을 디자인과 똑같이 구현해줘.
> 수치는 HTML 인라인 스타일이 정답이고, 색은 `tokens/splito-tokens.json`, 로고는 `assets/logo`를 그대로 써줘. 명세의 '확인 필요' 항목은 TODO로 남겨줘.
> 먼저 공통 컴포넌트(버튼, 입력, 배지, 카드, 바텀시트, 토스트, 탭바)를 만들고, 그다음 01번부터 한 화면씩 진행해줘.

18개를 한 번에 시키기보다 **공통 컴포넌트 → 화면 2~3개씩** 순서로 나누면 훨씬 정확합니다.

## 공통 규칙
- 기준 폭 390pt, 좌우 패딩 20, 라이트 모드, 한국어
- 폰트: Pretendard, 굵기 600/500/400만, 행간 160%, 자간 0, `word-break: keep-all`
- 아이콘: Iconoir(1.5px 선). 비행기·캐리어만 Material Symbols Rounded(`flight_takeoff`, `luggage`)
- 메인 CTA: 56h, radius 16, 짙은 남색 배경 + 흰 글자. 비활성은 `#E4E7EC` / `#A0A4AE`(투명도 쓰지 않음)
- 입력: 54h, radius 14, 테두리 1.5 `#E4E7EC`. 오류는 테두리와 문구를 `#D92D20`으로
- 외화 금액: 현지 통화를 크게 강조색으로, 원화는 작게 회색으로
- 색 의미: 민트 = 받을 돈·완료, 옐로 = 확인 필요·대기·예산 경고, 빨강 = 줄 돈·오류
- 토스트: 하단 pill, 1.8초 / 바텀시트: 상단 radius 28, 스크림 rgba(14,27,61,.45) 계열
- 상태 색 전환 120ms, 시트 320ms `cubic-bezier(0.2,0.8,0.2,1)`, 바운스 없음

## 정산 결과 핵심 로직 (명세 문서 없음)
- 내가 **보내거나 받는** 송금만 보여주고, 다른 사람끼리의 송금은 숨긴다.
- 탭: '보낼 돈 (n)' / '받을 돈 (n)'
- 카드: 상태 배지(송금 필요 / 확인 대기 / 입금 확인 필요 / 받았어요), 보내는 사람 → 받는 사람 동그라미(아래 이름), 금액은 오른쪽 위
- 상세 보기 펼침:
  - '상대 결제 품목'(내 몫 금액)
  - '본인 결제 품목'(상대 몫, 빨간색 − 차감)
  - 합계
- CTA는 검정으로 통일: 보낼 돈은 [보냈어요] → 확인 대기 + 취소, 받을 돈은 [받았어요] → 정산 완료 + 취소
- 계좌 [복사]는 받는 사람·금액·은행·계좌를 한 번에 복사한다.
