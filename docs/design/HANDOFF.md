# Handoff: Splito 모바일 앱 (MVP 화면)

## Overview
Splito(스플리토)는 여행·모임 동행이 각자 낸 결제를 영수증 사진·카드 승인문자·음성으로 올리면, AI가 품목 박스로 나누고 결제일 환율로 원화를 확정해 최소 송금으로 정산해주는 공동 가계부 앱입니다. 이 패키지는 MVP 10개 화면의 확정 디자인(홈 B안 + 정산 A안)과 로고·토큰을 담고 있습니다.

## About the Design Files
`design/` 안의 HTML 파일은 **HTML로 만든 디자인 레퍼런스**입니다. 의도한 모양과 동작을 보여주는 프로토타입이며, 그대로 배포할 프로덕션 코드가 아닙니다. 작업은 이 디자인을 **대상 코드베이스의 기존 환경(React Native/Expo 등)과 패턴으로 다시 구현**하는 것입니다. PRD 기준 앱은 Expo + Supabase이므로 React Native(Expo) 구현을 권장합니다.

- 확인 방법: `design/Splito App.dc.html`을 `support.js`와 같은 폴더에 둔 채 로컬 서버로 엽니다 (예: `npx serve design` → 브라우저에서 열기). 왼쪽 화면 목록이나 화면 요소를 눌러 이동합니다.
- 모든 스타일은 인라인 style로 작성되어 있어 수치를 그대로 읽어갈 수 있습니다. 화면 상태/데이터는 파일 하단 `class Component`의 `renderVals()`에 있습니다.

## Fidelity
**High-fidelity.** 색상, 타이포, 간격, 라운드, 인터랙션이 최종안입니다. 픽셀 단위로 재현하세요. 단, 기준 화면 폭은 390pt(iPhone 14/15)이며 실제 구현에서는 폭에 맞춰 늘어나야 합니다(좌우 패딩 20 고정).

- 바텀시트: 스크림 탭으로 닫기. 진입 320ms, cubic-bezier(0.2,0.8,0.2,1), fade + 위로 이동.
- 상태 색 전환 120ms. 바운스 없음.
- 프레스: 버튼 1px 아래로(translateY 1), 배경 한 단계 진하게.

## State Management
- auth: 로그인 여부, 약관 동의 4항목(필수 3), 닉네임.
- trips: 진행 중/정산 완료 목록, 각 여행의 상태(기록 중/정산 중/정산 완료), 내 순잔액.
- tripDetail: 총 지출, 멤버(게스트 포함, 대표자), 날짜별 지출 그룹(입력 방식, 결제자, 기록자, 원화/원본, 확인필요).
- expenseDraft: 인식 결과, 결제자, 품목 박스[{이름, 원문, 원본금액, 원화, 지정 멤버[], 확인필요}], 중복 후보.
- settlement: 서버 계산값(room_balances) — 사람별 낸 돈/부담/순잔액, 송금 목록[{from,to,금액,상태: 보낼 차례|확인 대기|받았어요}], 내 송금 기록 추가/취소.
- 정산·환율 계산 규칙은 PRD §7.2를 따름(서버가 정답).
